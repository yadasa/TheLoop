Per active user per month: 100 sent messages, 30,000 document reads, 1,000 document writes, 500 function requests averaging 0.25 seconds at 1 vCPU / 0.3 GiB, 5 uploaded photos, and 200 photo deliveries at 200 KiB each. Reads include initial room previews, reconnects, feed/profile/event loads, realtime delivery and private-media authorization. Assume six active rooms and repeated sessions; more visible rooms and wider fan-out increase reads.

Storage assumes a 12-month inventory of 4 MiB of indexed documents per user and 60 photos per user. This is a cost assumption, not an implemented automatic retention policy. Photos use a private callable with base64 overhead (4/3), so outbound function bandwidth is charged; a Storage free-download allowance does not make that client delivery free. A 1.5 KiB average is used for read-document network traffic. No video or audio streams are included.

Rates, formulas and limitations

Firestore Standard in Iowa: $0.03 / 100k reads, $0.09 / 100k writes, approximately $0.15 / GiB-month stored; free quotas 50k reads/day, 20k writes/day, 1 GiB stored and 10 GiB monthly transfer. Monthly free read/write subtraction below assumes traffic is evenly spread over 30 days; bursts consume less useful daily free quota. Index/rule reads count too. Firestore pricing.

Cloud Run request-based model: $0.000024 / vCPU-second, $0.0000025 / GiB-second, $0.40 / million requests, with 180k CPU-seconds, 360k GiB-seconds and 2M requests free. Internet delivery uses $0.12 / GiB for the initial North American tier; higher-volume tier discounts are deliberately omitted. Concurrency sharing can reduce compute, while cold starts and slow calls can increase it. Run pricing, network pricing.

Standard Storage in us-central1 is about $0.02 / GiB-month. The model allows 5 GiB free, $0.005 / 1,000 Class A and $0.0004 / 1,000 Class B operations, with the published free operation allowances. Storage pricing. Six scheduled jobs are approximately $0.30/month after three free jobs if that billing account’s free allowance is available; execution compute is separate. Scheduler pricing.

Free allowances can be shared with other services/projects on the billing account. Logs, builds, image storage, retries, notification fan-out and heavier maintenance jobs need a reserve; the fixed allowance is a budget placeholder rather than a measured bill. Email/password authentication is assumed; SMS, paid identity providers, search infrastructure, backups/PITR, maps, and analytics pipelines require separate pricing. No new subscription is required by this report.

Expo currently lists Free (15 Android + 15 iOS builds; updates to 1k MAU), Starter $19/month plus usage (updates to 3k MAU), and Production $199/month plus usage (updates to 50k MAU). These are update/build service limits, not a tax on every user who has the app installed. Expo pricing.

Monetize the organizers first

1 · Organizer Pro — test $49–149 / month

Keep member chat, safety, profiles and event discovery free. Charge organizers for branded hubs, event series, check-in operations, aggregate opt-in analytics, approved broadcast tools, CSV workflow improvements and multiple admins. Start with five paid design partners before building a large billing system.

2 · Sponsored community value — test $250–1,500 / campaign

Clearly labeled sponsor event cards, scholarship opportunities and relevant job listings. Let people opt out of sponsored discovery. Sponsors receive aggregate outcomes, never private messages or downloadable member contact lists.

3 · Member Plus — test $4–6 / month

Optional cosmetic customization, richer personal event collections, useful planning tools and saved-search alerts after those features exist. Never sell higher trust scores, better safety access or arbitrary ranking advantage.

4 · Event transactions — later

Once real organizers ask for ticketing, test a disclosed service fee on paid events. Payment processing, refunds, disputes, tax and mobile-store rules need a separate design and cost pass. Ticketing and subscription billing are not implemented by this report.

Illustrative validation targets: 10 organizers at $79 = $790 monthly gross revenue. At 10,000 MAU, 2% choosing a $5 membership = $1,000 gross/month, before churn, tax and fees. These are hypotheses, not conversion forecasts. Operator time and moderation are likely to cost more than Firebase at this stage.

What to measure before opening the doors

Track aggregated reads and function milliseconds per active user, delivered image bytes, successful message latency, notification opt-in/delivery, 7/30-day retention, organizer repeat use and moderation workload. Avoid logging message bodies. Run a two-account production smoke test, a physical Android test and a conference load simulation before widening access.
